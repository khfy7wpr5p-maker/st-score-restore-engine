# Third-party license records

Every runtime library, development tool, model adapter and model weight must have a review record before it is introduced.

A review must include:

- package or model name and exact version,
- canonical source,
- license identifier and license text location,
- redistribution and commercial-use terms,
- transitive obligations,
- whether weights, code and training data have different terms,
- approval status and related ADR or pull request.

The repository currently has no third-party runtime dependency or model weight.
